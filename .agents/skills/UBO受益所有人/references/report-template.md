# 固定报告模板

## 使用规则

严格按本文件生成报告：只替换 `{}` 占位符并按实际数量增删表格数据行，不得重命名、调序、合并或新增标题。提示段只在证据支持时填充；不支持时使用模板规定的缺失语句。最终报告不得包含本节说明。

## 1 报告用途

依据 FATF《40 项建议》中《建议 24 法人的透明度和受益所有权的释义》及中国人民银行 3 号令等监管要求，本报告按“控股识别 → 其他方式控制识别 → 高管层兜底”三步法完成受益所有人识别，并覆盖本次数据能够支持的身份基本信息。本报告企业事实仅来自本次 cisp-mcp 返回的结构化数据。

---

## 2 受益所有人

### 2.1 识别方法

### 数据来源

本报告企业事实数据仅由 cisp-mcp 在本次任务中返回，采集时间 {YYYY-MM-DD HH:MM:SS}。本报告未使用网络搜索、其他 MCP 或模型记忆补充企业事实。

### 适用标准

| 合规标准 | 条款 |
| --- | --- |
| 央行 3 号令 | 中国境内金融机构 UBO 识别 25% 持股阈值 |

### 免责声明

1. 本报告基于本次取得的企业登记及股权结构化数据生成，无法识别未披露的代持、协议控制、一致行动安排，须结合客户访谈、关联交易审查、合同尽调等手段综合判断。
2. 本报告基于工商登记维度的 UBO 识别与关联企业网络分析。需补充 UBO 个人司法画像、UBO 反向验证、UBO 关联企业合规扫描、历史 UBO 追溯等深度能力时，应通过专项尽调流程补强。
3. 境外主体（BVI / Cayman / 香港等）穿透可能受限。
4. 国际制裁清单（OFAC / UN / EU）不在本报告覆盖范围。对高风险客户，必须配合专业制裁筛查工具完成制裁命中检查。
5. 本报告仅供金融机构反洗钱合规内部尽调使用，不构成任何法律或商业决策建议。

## 篇章完整性清单

最终报告必须依次包含：

1. `# 受益人 · 身份基本信息报告`
2. 企业二级标题与七项报告头部
3. `## 执行摘要`
4. `## 1 报告用途`
5. `## 2 受益所有人` 及 `2.1` 至 `2.4`
6. `## 3 基本信息` 及 `3.1` 至 `3.6`
7. `## 数据来源与免责声明` 及三个子章节

不得把“待补充核验事项”改成新章节，不得新增股权图、风险评分、关联网络或建议授信章节。
