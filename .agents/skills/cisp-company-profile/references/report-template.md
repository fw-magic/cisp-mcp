# 企业一页纸画像报告模板

按实际数据删减占位项，不要原样输出花括号。先构建统一证据模型，再从同一模型生成聊天文本和 PDF。

## `both` 聊天摘要模板

聊天摘要保持约 300–600 个汉字，不重复 PDF 明细：

```markdown
## {规范企业名称}｜企业画像摘要

- **主体：** {登记状态、成立日期、行业和注册资本原值}
- **核心资产：** {可得维度总量；失败维度不得写 0}
- **股权与经营：** {主要股东、主要人员、分支或对外投资的最关键事实}
- **提示关注：** {最多 3 条，区分目标企业自身与关联主体}
- **数据边界：** {成功 N 个维度、空结果 N 个维度、未完成 N 个维度}

[下载 PDF 企业画像]({最终 PDF 的绝对路径})
```

`pdf` 格式只保留企业名称、查询日期、模式、必要的数据缺口和 PDF 链接。

## `md` 完整报告模板

```markdown
# {规范企业名称}｜企业一页纸画像

> 统一社会信用代码：{代码或“未披露”}  
> 查询日期：{YYYY-MM-DD}｜模式：{精简版/标准版/完整版}｜数据源：CISP MCP

## 1. 执行摘要

- **主体状态：** {登记状态；如存在注销/吊销等关键日期一并说明}
- **业务定位：** {基于登记行业和经营范围的一句话事实摘要}
- **规模与年限：** {成立日期/存续年限；注册资本原值和币种}
- **核心资产：** {商标/专利/软著/作品著作权/许可/荣誉/ICP 的可得总量}
- **关注事项：** {最重要的 1–3 项事实；没有返回时使用谨慎措辞}

## 2. 主体与经营

| 项目 | 信息 |
| --- | --- |
| 法定代表人 | {值} |
| 企业类型 | {值} |
| 成立日期 | {值} |
| 注册资本 | {原值 + 币种} |
| 注册地址 | {值} |
| 登记机关 | {值} |
| 所属行业 | {值} |
| 经营期限 | {值} |

**经营范围摘要：** {忠实压缩，不改变许可性表述}

## 3. 股权与治理

**股东概览：** {共 N 名/本次返回 N 名；最多列 5 名}

| 股东 | 类型 | 出资比例 | 认缴信息 |
| --- | --- | --- | --- |
| {名称} | {类型} | {原始比例} | {金额/币种/日期} |

**主要人员：** {姓名—职务，最多 5 人；其余写“另有 N 人”}  
**经营网络：** {分支机构、对外投资、网站/网店的数量和代表项}

## 4. 经营资产与资质

| 维度 | 数量/状态 | 代表性记录 |
| --- | --- | --- |
| 商标 | {totalCount 或查询状态} | {最多 2 项} |
| 专利 | {totalCount 或查询状态} | {最多 2 项} |
| 软件著作权 | {totalCount 或查询状态} | {最多 2 项} |
| 作品著作权 | {totalCount 或查询状态} | {最多 2 项} |
| 行政许可 | {totalCount 或查询状态} | {最多 2 项} |
| 荣誉资质 | {本次返回 N 项或查询状态} | {最多 2 项} |
| ICP 备案 | {totalCount 或查询状态} | {最多 2 项} |

## 5. 关联与舆情

> 仅完整版保留本节。

- **投资与任职关联：** {按关系类型统计；最多列 5 个公开关联线索}
- **近 90 天舆情：** {时间范围、命中总量、最多 3 条标题/日期/来源/标签}
- **边界：** 关联和舆情用于线索发现，不代表实际控制关系或经核验的司法、监管事实。

## 6. 风险事实

| 主题 | 本次查询结果 | 关键事实 |
| --- | --- | --- |
| 经营状态 | {值} | {吊销/注销/清算等日期或“未返回异常状态”} |
| 执行与失信 | {数量/状态} | {最多 3 条案号、法院、日期、状态} |
| 经营异常/严重违法 | {数量/状态} | {最多 3 条} |
| 行政处罚 | {数量/状态} | {最多 3 条决定日期、机关、文号} |
| 股权与担保事项 | {冻结/出质/抵押数量或状态} | {最多 3 条} |

## 7. 数据说明

- **成功维度：** {列表}
- **空结果维度：** {列表；说明只是本次未返回相关公开记录}
- **未完成维度：** {列表及简短原因}
- 本画像基于查询时点的公开数据摘要，不构成法律、财务、投资或准入意见。
```

PDF 与 Markdown 必须复用同一证据模型中的原值。PDF 首页可以压缩文字，但不得改变数量、日期、比例、主体范围或风险状态。

## 压缩规则

- 精简版删除“经营资产与资质”“关联与舆情”，将“风险事实”顺延编号。
- 标准版删除“关联与舆情”，将“风险事实”和“数据说明”顺延为第 5、6 节。
- 表格中没有有效内容的行直接删除，不写一排“未披露”。
- 一节超过 5 行明细时保留总数和最重要的 3–5 行，其余用“另有 N 条”。
- 经营范围超过约 160 个汉字时做忠实摘要，并说明为摘要。
- 重点关注事实放在执行摘要；普通提示不要堆叠成风险结论。

## 表述示例

推荐：

- “本次查询未返回经营异常记录。”
- “接口返回行政处罚 2 条，其中 1 条决定日期为……”
- “近 90 天公开舆情命中 8 条，以下为接口首批返回且取得详情的 3 条。”
- “该维度查询未完成，不能据此判断是否存在相关记录。”

避免：

- “企业无任何风险。”
- “该企业完全合规。”
- “第一页共 5 条，因此总量为 5。”
- “存在负面舆情，所以该事件已经证实。”
- “根据股东和任职关系，可确定实际控制人为……”
