# 客户可见语言规范

生成最终 Markdown 前完整读取本文件。内部证据模型可以保留工具、产品状态、返回结果和失败原因；客户可见的标题、正文、表格、提示语、数据来源与免责声明只能呈现企业事实、分析结论和资料边界，不得暴露查询过程或系统运行状态。

## 基本原则

1. 以企业、股东、控制主体或资料事实为主语，不以产品、接口、系统、模型或查询过程为主语。
2. 把运行状态转换为资料边界，把内部判断转换为专业分析；转换不得提高证据强度。
3. 优先使用明确日期或资料时点。避免用“本次”指代一次机器执行。
4. 同一段最多使用一次“现有资料”；后续直接陈述事实或使用“相关信息尚待核验”，避免机械重复。
5. 无数据时删去非必要模块；固定表格必须占位时，使用简洁的业务边界，不写接口状态。

## 客户文本禁用表达

最终报告不得出现以下表达及其带空格变体：

- 产品识别、产品返回、产品结论、产品聚合
- 返回、完整返回、部分返回
- 本次返回、本次未返回、本次未完成、本次未识别、本次未取得、本次路径、本次穿透
- 接口显示、接口返回、接口原值、查询失败、当前不可用
- 0 命中、零命中、聚合值、数据断点、路径互证
- 模型识别、模型判定、系统识别、系统判定、状态码
- MCP 工具代码、产品码、字段路径和内部证据编号

“水滴征信 MCP”作为数据服务品牌可出现在数据来源和页眉页脚，不属于禁用表达。

## 转换表

| 内部含义 | 客户可见表达 |
| --- | --- |
| 产品直接识别控制人 | 现有股权与控制关系资料指向 `{主体}`；证据充分时直接写 `{主体}为实际控制人` |
| 仅有单一控制结论 | 现有控制权资料将 `{主体}` 列为控制主体，相关控制链条尚待交叉核验 |
| 产品未识别控制人 | 现有资料尚未明确实际控制人 |
| 产品返回管理层名单 | 现有资料列示 `{N}` 名经营管理人员；该名单反映管理层范围，不等同于持股受益人 |
| 最终受益路径不可用 | 最终受益路径尚未完整还原 |
| 路径互证完成 | 相关结论已由工商股权及控制关系交叉印证 |
| 路径未完成互证 | 相关控制链条尚待交叉核验 |
| 股东列表只返回部分 | 在可核验的股东范围内 / 从前 `{N}` 大股东结构看 |
| 查询无结果 | 相关资料尚未显示 `{事项}`；只有覆盖范围与时点明确时才可使用 |
| 查询失败或范围不完整 | `{事项}` 的最新情况尚待核验 |
| 0 命中 | 截至 `{日期}`，在 `{明确范围}` 内未发现 `{事项}` 记录 |
| 当前状态未返回 | 最新存续或解除状态尚待核验 |
| 聚合控制比例 | 综合控制比例 / 相关控制关系对应比例 |
| 数据断点 | 控制链条尚未完整穿透 / 相关境外层级资料尚待补充 |
| 模型判定为脆弱 | 从股权集中度与表决权信息看，控制权稳定性偏弱 |

## 证据强度保持

- 内部仅有单一产品结论时，不得因语言润色改写成“已经工商与公开披露确认”。
- 内部状态为无结果时，不得改写成“未发现”或“为零”；只有查询成功、覆盖范围和资料时点均明确时，才能陈述范围内未发现记录。
- 路径缺失时写“尚待交叉核验”或“尚未完整穿透”，不得写“已锁定”。
- 管理人员名单只能解释为管理层范围，不得改写成最终受益人名单。
- “综合控制比例”只替换展示名称，不改变底层比例含义、精度或来源口径。

## 推荐句式

- `{企业简称}股权较为分散，从前十大股东结构看，第一大股东持股{原始比例}，前三大股东合计{允许展示值}。`
- `现有股权与控制关系资料指向{主体}为实际控制主体，相关结论可由{控制链条}交叉印证。`
- `最终受益路径尚未完整还原；现有资料列示的{N}名经营管理人员仅反映管理层范围，不等同于持股受益人。`
- `{日期}存在{事项}记录，其最新存续或解除状态尚待核验。`
- `从股权集中度与现有表决权信息看，控制权稳定性偏弱，仍需核验{材料}。`

## 交付前检查

1. 对完整 Markdown 运行 `scripts/customer_facing_language_validator.py`。
2. 检查每个缺口都已转换为资料边界，没有泄漏产品、接口或运行状态。
3. 检查替换后没有把不确定事实升级为确定结论。
4. PDF 文本提取后再次执行同一禁用词检查；逐页目视确认自然换行和标点正常。
