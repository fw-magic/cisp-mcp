# 执行摘要一句话结论：证据压缩型写作规则

生成执行摘要前完整读取本文件。只模仿专业股权报告的信息组织方式，不复制任何参考企业的名称、数字、事件或结论。现有比例原值、证据边界、控制权认定和数据缺口纪律继续优先适用。

## 目标形态

- 输出一个连续段落；“一句话结论：”标签后不得出现列表、换段或手动换行。
- 证据充足时使用 5 至 7 个中文分号分句，正文建议 220 至 350 个中文字符。
- 数据不足时主动缩短为 3 至 4 个分句；不为达到长度或分句数补套话、补主体、补数字或补事件。
- 每个分句至少包含一个本次已取得的事实、原始数值、明确日期、可核验事件或如实的数据边界。
- 按“判断 → 证据 → 边界 → 收束”推进；不用过程独白，不罗列工具或产品码。

## 生成前证据清单

先在内部建立以下清单，再选择有证据的模块。未通过门槛的模块省略或使用降级表达。

1. 股权总体：直接股东是否完整、股比口径是否一致、控制路径是否存在重大断点。
2. 控制与受益：产品是否直接识别；是否至少有一条独立工商、股权树或控制路径互证。
3. 核心比例：直接持股、总持股、表决权分别有哪些原始字符串；不得补齐缺项。
4. 快照互证：是否取得法定披露或其他独立快照；比较时点、股东范围、持股数或比例是否一致；是否完成逐项核对。
5. 历史演化：最早和最晚可核验日期、去重后变更条数、主要变更类型；是否有融资或治理事件与变更时间对应。
6. 治理结构：员工持股平台、国资、产业资本、投资机构等类型、数量和代表主体是否可数且有事实支持。
7. 权利受限：出质、冻结、担保分别是否查询成功且覆盖范围明确；历史解除状态是否有记录支持。
8. 最近节点：最近一次重要股权或治理事件的日期、事项和可直接支持的影响。
9. 稳定性：复用第七章阈值与事实；列出协议、代持、特殊表决权或披露快照等仍待核验事项。

## 固定组织顺序

仅选取有证据的模块，保持以下相对顺序；相邻短模块可以合并为一个分句。

1. 企业股权总体判断。
2. 实际控制人或最终受益所有人结论；紧随其后写括号内核心比例。
3. 当前工商股东与独立披露快照的互证结果。
4. 历史股权及工商变更的跨度、数量和主要特征。
5. 员工持股平台、国资、产业资本或投资机构等治理构成。
6. 当前状态与历史状态并列的出质、冻结、担保情况。
7. 最近一次重要股权或治理事件及其直接影响。
8. 控制权稳定性结论和继续核验边界。

## 可复用骨架

```text
{企业简称}{股权总体判断}，{控制人或受益所有人识别结论}（{姓名或主体}：{直接持股原值}直接持股 + {总持股原值}总持股 + {表决权原值}表决权）；{当前工商股东与指定时点独立快照的逐项互证结果}；{可核验时间跨度与去重后变更数量 + 主要变更类型或已互证的融资/治理节奏}；{员工持股平台 + 国资 / 产业资本 / 投资机构等股东构成及治理特征}；{出质 / 冻结 / 担保的当前状态 + 有明确记录的历史解除状态}；{最近重要事件日期 + 事项 + 直接影响}；{控制权稳定性 + 尚待核验边界}。
```

只保留实际取得的比例项。三项比例不齐时，不得保留三个空槽，也不得以其他比例替代。

## 证据门槛与降级表达

- “股权结构清晰透明”：仅在直接股东完整、比例口径一致且控制路径无重大断点时使用。否则写“当前股权结构基本可识别”；股东清单不完整时写“在可核验的股东范围内，股权结构基本可识别”。
- “锁定实际控制人 / 最终受益所有人”：仅在产品直接结论与至少一条独立路径一致时使用。仅有单一结论时写“现有控制权资料将 `{主体}` 列为控制主体，相关控制链条尚待交叉核验”；仅有候选线索时写“相关控制线索指向 `{主体}`，控制链条尚待交叉核验”。
- “完全一致 / 100%一致”：仅在时点和口径一致、逐名逐项核对完成且没有差异时使用。部分核对时写“已核对项目一致，其余信息尚待交叉核验”。未取得独立快照时省略该模块。
- “历史变更有序推进 / 与融资节奏一致”：仅在融资或治理事件与工商变更存在明确时间对应时使用。否则只写时间跨度、去重条数和主要变更类型。
- “未发现相关记录”：仅在对应的出质、冻结或担保查询成功且覆盖范围与日期明确时使用，写成“截至 `{日期}`，在 `{明确范围}` 内未发现 `{事项}` 记录”。产品无结果、失败或范围不完整时写“相关事项的最新情况尚待核验”或省略，不得改写成零；客户报告不得使用“0 命中”。
- “治理优化”：仅在变更内容与适用治理文件、可靠披露或明确治理效果互证时使用。单独的董监高增减只写客观变更。
- 禁止写“符合 IPO 申报条件”“具备 IPO 申报资格”或等价法律、监管结论。证据充分时最多写“当前证据未显示明显影响股权稳定性的事项，仍需律师、审计师及保荐机构结合申报口径核验”。

## 三种条件化表达

### 证据充分

使用 5 至 7 个分句。允许“清晰透明”“锁定”“完全一致”“在明确范围内未发现相关记录”等强表达，但必须逐项满足上节门槛；最后以稳定性结论和专业复核边界收束。

```text
{企业简称}股权结构清晰透明，{控制/受益结论及原始比例}；{同口径独立快照逐项核对结果}；{历史跨度、去重条数与已互证的演化特征}；{股东类型与治理构成}；{权利受限当前状态与历史状态}；{最近重要事件及直接影响}；{稳定性结论与专业复核边界}。
```

### 部分路径或披露快照缺失

使用 4 至 6 个分句。将强判断降级为“基本可识别”“现有控制权资料指向”“相关控制链条尚待交叉核验”；没有独立快照时直接省略一致性比较，不写“未取得快照但……一致”。

```text
{企业简称}当前股权结构基本可识别，{现有控制权资料指向及已取得的原始比例}，但{尚待交叉核验的控制链条}；{可核验的历史变更事实}；{有事实支持的股东构成}；{已核验的权利受限事实或最新情况尚待核验}；{稳定性判断及待取得材料}。
```

### 未识别实际控制人或股权较分散

使用 3 至 4 个分句。不得把第一大股东、管理层名单或共同任职主体改写成实际控制人；以集中度、尚未明确实际控制人的资料事实和协议安排缺口为中心。

```text
{企业简称}股权较为分散，第一大股东持股{原始比例}、Top3 合计{允许计算的原始展示值}；现有资料尚未明确实际控制人，{表决权或一致行动安排缺口}；{历史变更或股东类型构成事实}；从股权集中度与表决权信息看，控制权稳定性{结论}，仍需核验{协议、表决权委托或其他关键材料}。
```

## 句式与排版纪律

- 优先使用“判断 + 括号内核心数字”“当前状态 + 历史状态”“日期 + 关键事件 + 直接影响”。
- 允许使用“直接持股 + 总持股 + 表决权”“员工持股平台 + 国资 / 战投机构”等紧凑并列，但不得用加号掩盖口径差异。
- 使用中文分号 `；` 分隔信息单元；段落中不得出现项目符号、Markdown 列表、硬换行或第二个“一句话结论”标签。
- 比例、人数、日期、变更条数和主体名称逐项回查内容源；接口比例逐字保留，不补零、不截断、不四舍五入。
- PDF 只对同一段落自然换行，不把分句拆为多个段落，不缩小字号或压缩行距。

## 交付前验收

1. 确认结论是单段，分句数量与证据充分度匹配。
2. 逐字核对所有比例、人数、日期、条数和主体名称。
3. 逐项检查强表达门槛；未满足即降级或删除对应模块。
4. 检查没有为了凑够 220 至 350 字补造事实；数据不足时允许缩短。
5. 检查没有 IPO 资格、法律认定或监管通过等越界结论。
6. PDF 渲染后确认引用块自然换行，无裁切、重叠或异常分页。
7. 按 `customer-facing-language.md` 检查没有产品、接口、返回状态、命中、聚合值、数据断点或模型判断等内部表达。
