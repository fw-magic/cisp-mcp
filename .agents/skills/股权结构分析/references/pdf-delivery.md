# 股权结构穿透分析 PDF 交付规范

仅在 `SKILL.md` 的 PDF 能力检查全部通过后读取并执行本文件。PDF 必须与 `SKILL.md` 中“严格复刻篇章”的 Markdown 报告使用同一内容源；不得引入其他技能的章节、字段、话术或报告结构。

## 生成顺序

1. 先完成语义验收后的完整 Markdown 报告，确认企业副标题、八项报告头部、执行摘要、八个业务章节和最终数据来源与免责声明齐全。
2. 使用最终字体生成仅含“正文测试”和“粗体测试”的临时 PDF，确认常规与粗体映射到不同且覆盖简体中文的 PostScript 字形，并渲染预览确认肉眼可辨。
3. 以该 Markdown 报告为唯一内容源生成 PDF，不重新归纳、删节、扩写或调整章节顺序。
4. 输出 `output/pdf/{company_name}-股权结构穿透分析.pdf`。中间 DOCX、字体测试 PDF 和预览图只作为本次临时文件。

## 固定版式

- 页面使用 Letter，215.9 × 279.4 mm；上、下页边距 20 mm，左、右页边距 25 mm，可用正文宽度固定为 165.9 mm。
- 正文使用宋体或等价中文宋体常规字形，10.5 pt、固定行高 15 pt、段后 4 pt。不得用字符缩放、缩小字号或压缩行距减少页数。
- 主标题“股权结构穿透分析”使用黑体或等价中文黑体，18 pt、黑色、粗体、居中。企业完整登记名称作为副标题，14 pt、黑色、粗体、居中。
- “执行摘要”“一、数据来源与互证方法”至“八、潜在关联交易风险清单”“数据来源与免责声明”均作为一级标题，14 pt、粗体蓝色 `#4F81BD`。编号子节使用 12 pt、粗体蓝色 `#4F81BD`。
- 主标题与企业副标题之后按固定顺序展示：目标企业、统一社会信用代码、法定代表人、报告类型、报告生成、审计留档编号、穿透方向、控制权稳定性。八项使用 9 pt、固定行高 12 pt；标签使用实际中文粗体，内容使用常规字重。
- 正文、实体名称、比例、置信度、说明和表格数据使用常规字重。只允许主副标题、章节标题、元信息标签、执行摘要中的“一句话结论”“建议行动”、表头和免责声明标签使用实际中文粗体。
- 不添加页眉、页脚、页码、额外封面、证据索引、接口明细或报告使用说明。内容随有效数据自然分页，不强制压缩到固定页数。

## 中文字体

- macOS 存在 `/System/Library/Fonts/Supplemental/Songti.ttc` 时，正文首选 `STSongti-SC-Regular`（`subfontIndex=6`），粗体使用 `STSongti-SC-Bold`（`subfontIndex=1`）；标题可使用 `/System/Library/Fonts/STHeiti Medium.ttc` 中的 `STHeitiSC-Medium`（`subfontIndex=1`）。
- 其他环境必须选择实际包含简体中文 Regular 与 Bold 的字体，并用字体元数据确认两者 PostScript 名不同且覆盖报告字符。不得把同一 Regular 字形同时注册为 normal 和 bold，不得依赖阅读器合成粗体、描边或重复绘制模拟粗体。
- 使用 ReportLab 时分别注册常规和粗体字体并建立字体族映射。Markdown 的 `**文本**` 只是语义标记；排版时必须转换为实际粗体字形，动态正文先做 XML 转义。
- 中文字体预检失败即停止 PDF 流程并执行 Markdown 降级，不得生成使用乱码、缺字或伪粗体的报告。

## 段落与提示语

- 执行摘要中的“一句话结论”使用左侧 2 pt 蓝色竖线或等价引用块样式，不使用底色；正文 10.5 pt。
- “建议行动”保留单段编号句式，不拆成新增章节。
- 各章表后的说明、穿透提示、一致行动提示和关联交易提示使用 9.5 pt、常规字重；保留原篇章位置，不移动到脚注或附录。
- “数据来源与免责声明”必须位于第八章之后；数据来源为独立段落，免责声明保持四条编号列表。

## 表格

- 使用黑色 0.5 pt 网格线，无表头底色；表头使用实际中文粗体、左对齐并跨页重复。正文使用 9 pt、固定行高 12 pt、常规字重、左对齐、垂直居中。
- 允许表格自然跨页和长单元格拆分。不得使用 `KeepTogether`、`keepWithNext`、整块容器或手动分页符保护表格、章节或说明；跨页只重复表头，不重复章节标题。
- 按 165.9 mm 可用宽度使用以下列宽比例；比例按表格总宽度换算，不得增加、删除或重命名列：
  - 执行摘要关键判断：28% / 52% / 20%。
  - 数据来源与互证：22% / 32% / 20% / 26%。
  - 主体基本信息：28% / 72%。
  - 股东全景：6% / 28% / 14% / 18% / 15% / 19%。
  - 股东类型分布：24% / 16% / 60%。
  - 集中度分析：30% / 25% / 45%。
  - 实控人 / 受益所有人：7% / 15% / 18% / 15% / 15% / 15% / 15%。
  - 间接控制路径：31% / 18% / 21% / 30%。
  - 一致行动人 / 配偶关联：18% / 22% / 30% / 30%。
  - 关键变更时间轴：16% / 18% / 36% / 30%。
  - 历任法定代表人：20% / 42% / 38%。
  - 疑似一致行动主体：25% / 18% / 37% / 20%。
  - 控制权脆弱性：32% / 30% / 38%。
  - 潜在关联交易风险：20% / 23% / 37% / 20%。
- 股东全景数量较多时允许跨多页；不得通过只保留前几名来替代 `SKILL.md` 已生成的完整内容。数据过长时换行，不得缩小到规定字号以下。

## 生成与验收

1. 语义检查以下顺序完全一致：主标题 → 企业副标题 → 八项报告头部 → 执行摘要 → 一至八章 → 数据来源与免责声明。
2. 核对执行摘要六项关键判断、三条建议行动、第三章三个子节、第四章三个子节、第五章两个子节以及所有固定表头均存在；没有新增章节或遗失说明段。
3. 检查所有企业比例沿用 Markdown 原值，TopN 等允许计算项与 Markdown 一致，未披露项没有被 PDF 排版阶段补造。
4. 使用可控的单一 PDF 生成路径完成排版；直接生成不可用时最多改用一次已经存在且可验收的 DOCX 中转路径，不得在多个渲染器之间循环切换。
5. 使用 `pdfplumber`、`pypdf` 或等价工具检查页数、Letter 尺寸、文本可提取性、标题、表头字体、常规与粗体 PostScript 字形以及未替换占位符。
6. 使用 Poppler 或等价工具把最终 PDF 全部页面渲染为 PNG，并逐页检查中文、字号、行高、边距、表格、引用块、自然分页、裁切、重叠、黑块和异常空白。除最后一页外，后续仍有连续正文但当前页空白超过可用正文区约三分之一时，视为分页失败。
7. 只有字体元数据和逐页视觉检查均通过时才交付 PDF。验收通过后删除本次全部临时文件，只保留最终 PDF。

## Markdown 降级

- 用户指定 `--format md`、运行环境明确标记为轻型模型、PDF 能力检查失败或 PDF 流程任一步骤失败时，直接在聊天中输出同一内容源的完整 Markdown 报告。
- PDF 流程失败时先删除不完整 PDF 和临时文件，再说明：`PDF 生成未完成：{原因}，已改为聊天内联 Markdown 报告。`
- 不循环重试，不交付损坏或未经逐页验收的 PDF，不以 `.md` 文件链接、摘要或局部章节代替聊天内联完整报告。
